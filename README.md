# minecraft-clone-p5js
Custom Minecraft version made in p5.js

My Craft uses the p5.js library to procedurally generate a 2D Minecraft-like world where you can move, break and place blocks

First versions of the project where made on the [p5.js web editor](editor.p5js.org) from January 2023 to mid March of the same year. Latest version of that year can be tested [here](https://editor.p5js.org/MarcoGaLo/full/N3ZoZR6uM)
